# 議事録の作り方（引き継ぎ書）

事前検討会・打合せの録音から議事録を作る手順。
2026年8月28日の東京ビル手摺嵩上げ工事 事前検討会で確立し、2026年9月17日の新宿フロントタワー 外壁改修（シール打ち替え）工事 事前検討会で、会社フォーム（⑤事前検討会議事録.xls）への提出と上司修正を経て確定した。

**【2026.9.19 改訂】** 3章を実物のフォームに差し替え。4章（文章の整形）・6章（フォームへの収め方と印刷）を新設。

---

## 0. 大原則

**会社のフォームが最優先。レイアウトを自分で作らない。**

フォームを渡される前に自分で表を作ると、フォームが出てきた時点で作り直しになる。
手元になければ、作り始める前に「フォームをください」と言う。

**配布資料に書いてあることは議事録に書かない。**

工期・体制・仕様・施工要領は施工計画書を見れば分かる。写した瞬間に議事録は資料の劣化コピーになる。
書くのは、その場で出た**質問・指摘・補足・回答**だけ。

**議事録の主役は、支店から指示されたこと。**

フォームでいえば「検討、指示事項」の列。ここが埋まっていない議事録は、何のために開いた会議か分からない。
1件を「指示・回答」で閉じる。回答で片づいた話はその場で終わり、片づかなかったものが宿題として残る。
宿題を別紙に分けると同じ内容を二度書くことになる。1本にまとめる。

**議事録は文字起こしではない。**【2026.9.19 追加】

口語をそのまま並べたものは議事録にならない。社外に出しても通じる書面調に整形する（4章）。

## 1. 用意するもの

| 必要なもの | 用途 | なくても作れるか |
|---|---|---|
| **会社のフォーム（空欄のExcel）** | 最終出力の器 | 不可。これがないと作り直しになる |
| 文字起こしテキスト | 本文 | 不可 |
| **参加者一覧（会議招待の画面・出席者返信）** | 社名・氏名・所属の正表記 | 不可。文字起こしの当て字をそのまま書かないため |
| 録音ファイル（m4a等） | タイムスタンプの算出 | 時刻を入れる場合は不可 |
| 施工計画書（PDF） | 社名・氏名・数値の確認 | 作れるが精度が落ちる |
| **前回の議事録** | 書き方と、支店の指摘パターンの確認 | あれば精度が上がる |
| 図面 | 場所の記号と名称の照合 | あれば良い |

**渡し方**：全部まとめて渡す。文字起こしだけ渡すと、穴を埋めようとして資料の丸写しや推測が始まる。

## 2. 手順1　会話版（作業用・保管用）

**位置づけ：手元に残す版。関係者への配布はしない。**

- 時刻＋表題の見出しで、開会から閉会まで並べる
- やりとりのある部分は発言のまま残す。後から録音に戻る目印になる
- 提出用（3章）は、この版から会話を整形して作る

### タイムスタンプの出し方

`ffprobe` で録音の長さを取り、文字起こしの位置で按分する。

```
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1 録音.m4a
```

例：4885秒＝1時間21分25秒。話題の切れ目が全体の20%地点なら 16:17。
**概算であることを明記する。** 録音がなければ時刻欄は空欄のままにする。

## 3. 手順2　会社フォーム版（最終出力）

**位置づけ：これが提出物。ファイルは「⑤事前検討会議事録.xls」。**

### ヘッダー

| 欄 | 書くこと |
|---|---|
| 工事件名 | 正式な工事名 |
| 会議名 | 工事事前検討会 |
| 場所 | 丸の内事務所（Teams併用）のように、Teams併用かどうかまで書く |
| 日時 | 2026/9/17　13：00-15：00 |
| 出席者（支店） | 部署ごとの行に、正式な肩書きで書く。出席がない部署は「なし」と書く |
| 出席者（工事事務所） | 統括安全衛生責任者・元方安全衛生管理者は氏名で書く。他の出席者は下の行に並べる |
| 出席者（協力会社） | 会社名＋氏名＋担当工事。欠席者は欠席の理由と代読の有無まで書く |

### 明細の列

| 列 | 書くこと |
|---|---|
| **検討、指示事項** | 【表題】に続けて、支店・出席者から出た指摘・質問。**ここが主役**。計画書に書いてあることは書かない |
| 決定事項、保留事項 | 回答と、宿題の内容。**【宿題】の見出しは付けず、そのまま書く** |
| 元･協 | 元請は「元」、協力会社は略称社名（いづみ／まさる／大木組） |
| 重要度 | ◎〇△ |
| 確認者（現場） | 担当者名 |
| 確認者（事業部） | 同上 |

**元･協・重要度・確認者の3欄は、作成者（Claude）が書かない。**【2026.9.19 追加】
役割分担も重要度の基準も社内で決めるもので、録音からは判断できない。空欄で出し、こちらで記入する。

## 4. 文章の整形　【2026.9.19 新規】

上司修正版から確定した書き方。

### 語尾と文体

- 指摘・指示は「〜すること」で閉じる（例：必要な資格は作業方法に合わせて明示すること）
- 回答は「〜する」「承知しました」で閉じる
- 「〜だと思う」「〜のようだ」などの推測、経緯の説明、言い訳めいた言い回しは削る
- 人名は「大山氏」のように氏を付ける

### 用語は現場表記に直す

| 文字起こし | 議事録 |
|---|---|
| 骨 | 下地 |
| 着地用 | 着床用 |
| 落下防止の台付け | 落下防止ワイヤー |
| 乗り換え | 盛替え |
| 張りぼて | （書かない） |

### 書かないもの

- 「聞き取り不完全」などの注記
- 自己紹介だけの行
- 作成者側のミス（記載漏れ、図面から消えている等）
- 文字起こしの当て字の社名・人名

---

## 5. 判断に迷ったとき

| 迷い | 判断 |
|---|---|
| 資料に書いてあるが会議でも触れた | 書かない。指摘・質疑が出た場合だけ書く |
| 聞き取れない社名・氏名 | 参加者一覧・体制表・前回議事録から正表記を選ぶ。当て字で書かない |
| それでも特定できない社名 | 社名を書かず職種で書く（足場、養生・クリーニング） |
| 「承知」だけの返事 | 書く。受けた証拠になる |
| その場で決着した質疑 | 書く。宿題欄は空欄 |
| 説明しかなかった話題 | 書かない |
| フォームの列と内容が合わない | フォームに合わせる。列を足したり減らしたりしない |
| 原文にない項目を埋めたくなった | 埋めない。空欄で出し、渡すときに口頭で伝える |

## 6. フォームへの収め方と印刷　【2026.9.19 新規】

- **フォームの行高さは変えない。** 1件が1行に収まらない場合は、その件の行数ぶんセルを縦に結合して収める
- 1件が2ページ目にまたがらないよう、収まらなければ次ページの先頭から始める
- 印刷範囲は、内容が収まった最後のページまでにする。白紙のページを印刷しない
- フォントは原本のまま（ＭＳ Ｐゴシック）。明細は9ポイント
- フィルターは付けない
- 印刷は原本の設定（A4縦）のまま。記入用に配る場合のみA3に拡大する

## 7. 次回の検討会に向けた事前準備

**議事録は、会議が終わってから作るものではない。会議の前に器を作っておくと、当日の記録がそのまま議事録になる。**

### 作るもの2点

| 作るもの | 中身 |
|---|---|
| 司会進行台本（Word） | 計画書の章立てに沿って時間配分し、ブロックごとに「司会セリフ・説明担当・資料ページ・押さえる数値・想定される指摘」を並べる |
| 記入用シート（Excel） | 会社のフォームに、台本と同じブロック見出しだけを入れ、下に空行を用意したもの |

**台本のブロック番号＝議事録の見出し番号にする。**

### 想定される指摘は、前回の議事録から抜く

支店は毎回ほぼ同じことを聞く。繰り返し出ているもの：

- 資格（作業指揮者・玉掛け・有機溶剤作業主任者・化学物質管理者・保護具着用管理責任者・特別教育の修了者名簿）
- 体制表の網羅（責任者、年齢、役割分担）
- 荷重の確認（メーカー確認、積載荷重、屋根・床の耐荷重）
- リスクアセスメントの抜け（使う機械の安全管理が入っていない）
- 搬入ルート・資材置き場・格納場所を図面に明示したか
- 出入口と立入禁止措置を明示したか
- 詰所・休憩所・トイレの扱い
- PAT CARE等の登録
- 未記入欄（作成者・承認者・審査者・月日・参加者）の記入

### 司会の型（4動作）

① 表題と資料ページを言う　② 説明者を指名する　③ 質疑を受ける　④ 宿題を復唱して閉じる

**④を飛ばすと議事録が書けない。**「◯◯さんが、いつまでに、何を」を必ず口に出してから次へ進む。
その場で仕様や数値を決めない。分からないものは「確認して回答します」で受けて宿題にする。

## 8. 出力先

案件フォルダ（共有ドライブ）に置く。

```
案件フォルダ/
  録音.m4a
  議事録_会話版.docx          ← 手順1（保管用）
  ⑤事前検討会議事録.xls       ← 手順2（提出物）
  司会進行台本.docx            ← 7章（次回用）
```

**コードのリポジトリには置かない。** 実名・電話番号・金額を含むため、置き場所として不適切。

## 9. 失敗記録

同じことを繰り返さないため。

1. 文字起こしだけ渡された段階で、情報の穴を埋めようとした。計画書が届くと、その内容をそのまま流し込んだ → 資料の劣化コピーになった
2. 宿題を別紙にして、本文にも同じ内容を書いた → 二度手間
3. 会社のフォームをもらう前に、自分でレイアウトを作った → フォームが出てきた時点で全部作り直し
4. 録音ファイルがないまま議事録を作ろうとした → 時刻が出せず、たたき台にしかならなかった
5. 議事録をコードのリポジトリに置こうとした → 実名・金額を含む文書の置き場所として不適切
6. **【2026.9.19】文字起こしの口語をそのまま書いた** → 議事録ではなく書き起こしになった。書面調に整形する
7. **【2026.9.19】文字起こしの当て字の社名をそのまま書いた（泉湾／三誠）** → 正しくは「いづみ・one」「サンセイ」。参加者一覧から選ぶ
8. **【2026.9.19】「聞き取り不完全」「記載が抜けていた」を議事録に書いた** → 議事録に関係ない。作成者側のミスも書かない
9. **【2026.9.19】決定事項欄に【宿題】の見出しを付けた** → 見出しは不要。内容をそのまま書く
10. **【2026.9.19】元･協・重要度・確認者を埋めようとした** → 社内で決める欄。空欄で出す

**渡す側への注意**：

- **最初に会社のフォーム（空欄のExcel）と参加者一覧を渡す。**
- 録音・文字起こし・施工計画書・前回の議事録を、**まとめて一度に**渡す
- 出来上がったものは、そのまま配らない。氏名・金額・社名は必ず突き合わせる

## 10. 応用：同じ進め方が使える書類

いずれも「**会社のフォームに落とし込む**」「**原文にない項目は補わず空欄で残す**」が共通。

| 書類 | 進め方 |
|---|---|
| 作業手順シート（リスクアセスメント） | 作業指示の文章を、区分（始業前・作業・片付け）ごとのステップに割り、ステップごとに危険有害要因と対策を立てる。重大性×可能性＝評価点、対策後に危険度が下がることを確認する |
| 作業指示書 | 時系列に並べ、確認欄を付ける。夜間作業はチェックを入れながら進められる形にする |

**止めたものは、必ず戻す手順まで書く。**
停止・遮断・撤去を伴う作業は、復旧までを1セットで書く。

## 11. 再現性について

**同じ手順で作れるもの**
- 会社フォームへの落とし込み、行の収め方、印刷設定
- 文章の整形（語尾・用語・書かないもの）
- 「資料を写さない」「指示されたことを主にする」という編集方針
- 司会進行台本の構成と、前回議事録からの想定指摘の抽出

**毎回変わるもの**
- タイムスタンプの精度。正確な位置が要る箇所は録音で確認する
- 文字起こしの品質。固有名詞と数値は必ず参加者一覧・計画書と突き合わせる
- 話題の切り方

**こちらで記入するもの**
- 元･協、重要度、確認者（現場・事業部）
